# 10-17-2026-Technica-project
When you open the project, you must have WSL installed through Windows Terminal. 
When you download WSL through the terminal, run: wsl -d Ubuntu python3 /home/billbo/gui_app.py
This will boot you into the weberlinux(weblinux) distro 
The topmost app on the left side of the distro is the .MP3 player 
The second app is The 1993 Doom; it can only run the first level due to the way it was downloaded
The third app is the Firefox web browser
The fourth app is the Notepad app
The fifth and final app is the File Manager
